- **agentica 破坏性变更集中释放**（e84fc48）：v1.4.16 将 MCP 收敛为仅支持 2.x、Layer 2 compact 不再产出 LLM 摘要，v1.4.14 移除 `edit_file` 改为 `apply_patch` + `write_file`——依赖旧版 MCP 1.x、摘要轮行为或 `edit_file` 的下游集成需主动迁移，是今日唯一有实际迁移成本的风险点。
- **cc-switch 建档确认为细分类目头部**（f878871）：单库管理 10 个 AI CLI/桌面应用的供应商、MCP、skills 配置并内建带熔断与故障转移的本地代理，Rust 后端约 21.3 万行，活跃度高（HEAD 即建档当日，v3.20.4）——“AI CLI 配置中枢”已从玩具演化为成熟桌面产品。
- **CC-Balancer 建档揭示新细分**（dfecb1f）：面向 Coding Plan 5 小时滚动额度的“规划实验室”，纯前端、无 API 请求，且 HEAD 提交即从拖拽交互模型大重构为表单+Prompt 生成——额度焦虑正在催生配套工具生态。
