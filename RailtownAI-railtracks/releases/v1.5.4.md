# RailtownAI/railtracks v1.5.4 情报简报

**BLUF**：v1.5.4（2026-09-09 发布）是一个以缺陷修复为主的维护版本，核心变化是 LLM 包隔离并引入可捕获的失败异常分类体系（#1492）、工具参数校验接入 Tool.__init__（#1521），以及 HIL 聊天 UI 渲染的安全清理（#1551）。

## 升级建议
- 建议升级：本次含 LLM 失败异常分类（#1492）与工具参数校验（#1521）两项行为性变化，长期看利于错误处理，但依赖 LLM 异常捕获逻辑的下游代码需自查。
- 重点回归：使用 LLM as a Judge 数值指标、HIL 聊天 UI、context injection 模板跨调用传递的场景。
- 依赖变更：pypdf、pymdown-extensions、setuptools 升级，并新增 pytz 显式依赖（duckdb TIMESTAMPTZ 转换场景），CI/打包环境需同步。
- 安全相关：#1551 清理聊天 UI 消息渲染，建议尽快合入；#1550 将 e2e workflow token 收敛为 contents: read，属 CI 权限加固。
