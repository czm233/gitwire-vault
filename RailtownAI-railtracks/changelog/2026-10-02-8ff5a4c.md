# Changelog — 2026-10-02（`9b894a3` → `8ff5a4c`）

## 新增

- **docstring 解析支持三种格式**：工具 docstring 不再强制 Google 风格，现支持 Google / NumPy / reST(Sphinx) 三种参数描述格式，解析结果一致；Google 的 `Args:` 也可写 `Arguments:` / `Parameters:`，reST 接受全部 Sphinx 参数字段名（`:param`/`:parameter`/`:arg`/`:argument`/`:key`/`:keyword`）；混用多风格时告警并按 Google → NumPy → reST 顺序只读其一（`fb34b0f`，packages/railtracks/src/railtracks/llm/tools/docstring_parser.py +325/-17、tool.py，测试 +578/+185）。文档新增「Supported docstring styles」三风格对照（docs/documentation/agent_design/tools/function_tools.md）。

## 修复

- **CLI `railtracks add` 参数解析**：`--force` 现在可放在 `<tool>:<skill>` 之前；原实现把首个非 `-` 开头参数当 spec，`--force` 在前时会误取（`8bfca9e`，packages/railtracks/src/railtracks/cli/__init__.py，新增 20 行单测）。

## 重构（文档/示例）

- **响应对象 API 统一为 `.content`**：全量文档与示例把 `result.text`、结构化输出的 `result.structured` 统一改为 `result.content`（结构化时 `.content` 即 schema 实例）（`8ff5a4c`，README.md、docs/scripts/*、docs/tutorials/walkthroughs/ryfa.md 等）。
- **示例风格规范化**：`agent_node` 返回类统一用 PascalCase 命名（`WeatherAgent = rt.agent_node(...)`）并传 `entry_point=WeatherAgent`（`8ff5a4c`，多处脚本与文档）。
- **模型名全量更新**：示例模型名 `gpt-5.4-mini` → `gpt-6-luna`、`claude-sonnet-5` → `claude-sonnet-5-5`、`gemini-3.7-flash` → `gemini-3.8-flash`（`8ff5a4c`，README.md、docs/scripts/providers.py、docs/documentation/getting_started/llm_setup.md、examples/* 等）。
