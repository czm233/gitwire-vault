# Changelog — 2026-09-25（`b28115b` → `2f1626e`）

本次仅 1 个提交 `2f1626e`（2026-09-24）：**修复 function node 中间件的类型推断（issue #1538）**——此前在 `function_node(middleware=[...])` 中混合任意两个预置中间件会让 mypy 把参数 ParamSpec 塌缩为 `Never`。修复方式为给 `Middleware` 增加第三个泛型参数 `_Constraint`（带默认值、协变，`Never` 表示槽位无关），并重写 `function_node` 装饰器重载（2f1626e）。

## 新增

- 新增静态类型回归脚本 `docs/scripts/function_node_typing.py`（+161 行，`assert_type` 覆盖空/单个/多个/复用/同步异步/自定义 wrap_node/pre+post verifier/全混合等场景，并含 3 个应被拒绝的错误签名用例）（2f1626e）
- 文档新增「组合多个预置中间件」示例段 `docs/scripts/prebuilt_middleware.py`（`--8<-- [start: combining]`），注明 #1538 修复背景（2f1626e）
- 单测新增两个组合场景：两个及三个不同预置中间件（Retry+Timeout、Retry+Timeout+MaxCalls）在同一位 `middleware=` 列表中可正常组合执行（`tests/unit_tests/middlewares/test_node_middleware.py`，2f1626e）

## 修复

- **#1538**：`function_node` 装饰器形式（`@rt.function_node` / `middleware=[...]` 不直接传 func）通过新增 `_FunctionNodeDecorator` Protocol 重载保持入参/出参类型推断，不再因混用中间件塌缩为 `Never`（`packages/railtracks/src/railtracks/built_nodes/function/node.py`，2f1626e）
- `pre_verifier`/`post_verifier` 的重载签名改为携带 `_MiddlewareSignature[_P, Never/_TOutput]` 约束：pre-verifier 仅约束调用参数、不约束输出类型（`prebuilt/middleware/pre_verifier.py`，2f1626e）

## 重构

- `Middleware` 由 `Generic[_P, _R]` 变为 `Generic[_P, _R, _Constraint]`，`_Constraint` 使用 `typing_extensions.TypeVar`（协变、默认 `_MiddlewareSignature[_P, _R]`）；公开的双参数 `Middleware[P, R]` 形式经默认值保持兼容（`middleware/core.py`，2f1626e）
- 槽位无关预置件（`Lock`、`MaxCalls`、`Retry`、`Timeout`）声明为 `Middleware[Any, Any, Never]` 以退出输出约束（各自文件，2f1626e）
- `function_node` 直接包装形式的 `middleware` 参数类型改为 `Iterable[Middleware[Any, Any, _MiddlewareSignature[_P, _TOutput]]]`（2f1626e）
- `scripts/docs_validation.sh` 改为多行参数调用 mypy，并新增 `--warn-unused-ignores`（收紧 docs/scripts 类型校验）（2f1626e）

## 破坏性变更

- 无（`Middleware` 第三泛型参数带默认值，公开 API 形式保持兼容；内部 `_MiddlewareSignature` 为私有符号，未核实是否有下游直接引用）
