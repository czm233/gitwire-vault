# Changelog — `e8b0590` → `9b894a3`（2026-10-01，4 提交 / 38 文件）

结论先行：本次两条主线——**context 系统全面接入事件流（可观测性）**、**工具 schema 在 PEP 563（延迟注解）下的正确解析**；另有 Conductr 托管评估文档与 AGENTS.md 技能确认机制强化。

## 新增

- **context 事件命名空间**：新增 `context.*` 六类事件（`context.creation` / `context.get` / `context.put` / `context.update` / `context.delete` / `context.completion`），每次 `rt.context` 调用与 run 两端的快照均记入事件流，事件带 `keys` / `values` / `level` 列（`334456e`，`packages/railtracks/src/railtracks/events/context.py`、`events/registry.py`）。
- **记录级别开关 `RAILTRACKS_CONTEXT_EVENTS`**：`0` 关闭、`1` 只记 keys、`2`（默认）记 keys+values；非法值回退 2 并告警（`events/context.py` 的 `ContextEventsLevel`）。
- **value 快照语义**：`_snapshot` 在调用时刻深拷贝值，之后原地修改不再污染事件日志（文档明确警告 `get(...).append(...)` 这类原地编辑不产生 put 事件，level 1 下完全不可见）（docs/documentation/advanced/context.md）。
- **`emit_snapshot` 接入运行两端**：`interaction/_call.py` 的 `_start` / `wrapped_fut.finally` 分别发 `ContextCreation` / `ContextCompletion`（`334456e`）。
- **线程安全同步发事件**：新增 `publish_event_nowait` / `emit_nowait`，跨线程经 `call_soon_threadsafe` 交付到 observer loop；`Observer` 暴露 `is_observing` / `loop` 属性；sync 节点体内的 context 调用也能被正确归属（spatial parent 在调用线程解析）（`events/send.py`、`observability/publish.py`、`observer.py`）。
- **`context_spatial_parent` 解析**：context 事件父级解析为最近的 node 或 LLM 调用（+最近的 middleware），run 外调用为 null node parent（`events/_resolve.py`）。
- **`ExternalContext.items()`**：抽象方法 + `MutableExternalContext` 返回拷贝视图，供 completion 快照取全量键值（`context/external.py`）。
- **Literal 参数处理器**：新增 `LiteralParameterHandler`，`Literal["fast","slow"]` 生成带 `enum` 的 string 参数；混合类型字面量生成排序后的类型列表；非原始类型 Literal（如 Enum 成员）回退 object（`9b894a3`/#1580 之外亦含，`llm/tools/parameter_handlers.py`）。
- **PEP 563 类型解析**：新增 `llm/tools/typing_utils.py::resolve_type_hints`，当任一注解为字符串时经 `typing.get_type_hints(include_extras=True)` 解析；`Tool.from_function` 与 `validate_tool_manifest_against_function` 均改为用解析后注解匹配 handler / 校验 manifest；不可解析时告警并回退 object，提供 `ToolManifest` 可跳过告警（`9b894a3`，#1580）。
- **Conductr 托管评估（Hosted Evaluations）**：新增 `docs/evaluations/conductr_hosted.md` + 示例脚本 `docs/scripts/evaluations/conductr_hosted.py`（FastAPI `/evals/run` 端点，需 `railtownai>=2.1.2` 的 `HostedEvaluationResponse`），文档导航重组为 Conductr 子目录（`689c3fe`）。
