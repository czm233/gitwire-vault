# Release 简报：agentica v1.4.16

**BLUF**：v1.4.16 将 Layer 2 上下文压缩从「LLM 摘要」改为「空窗换窗」——不再调用 LLM 或 `/responses/compact` 做摘要，旧对话保留在 session JSONL，交接写入旁边 `<session>.notes.md`；交互 CLI 新增 attach 注入与外部 hooks（默认关），MCP extra 收紧为仅支持 2.x。

## 升级建议
- **建议常规升级**，但涉及压缩行为的调用方需自查：依赖 LLM 摘要输出或 `/responses/compact` 接口的集成会受影响。
- 如有自定义压缩/摘要管线，升级前确认是否依赖旧的摘要产物格式。
- 自托管（`docker compose up -d --build`）会自动应用；桌面版安装包由 CI 稍后挂载，**未签名**，首次启动需手动解锁（见 README）。
- 使用 MCP extra 的团队升级前确认自己的 MCP server 版本已符合 2.x。

## 变更明细
1. **Layer 2 compact 机制重写（核心变更）**：
   - 不再调用 LLM 或 `/responses/compact` 做摘要，改为「空窗换窗」（窗口切换不消耗上下文预算/推理成本——未核实内部实现细节）。
   - 旧对话完整保留在 session JSONL，可用 `search_session` 检索。
   - 会话交接信息写入 `<session>.notes.md`（位于 session 文件旁）。
2. **交互 CLI 新增 attach**：可选功能，允许向正在运行的会话注入用户消息。
3. **外部 hooks**：新增 `settings.hooks` 配置，默认关闭，不影响现有用户。
4. **MCP extra**：仅支持 MCP 2.x，放弃对旧版本的兼容（未核实具体断点版本号）。
