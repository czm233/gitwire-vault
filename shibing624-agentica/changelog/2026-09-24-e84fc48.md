- v1.4.16（2026-09-15，tag v1.4.16）：Layer 2 compact 改为空窗换窗，不再 LLM 摘要；旧对话经 `search_session` 查询；CLI 可选 attach 与外部 hooks（默认关）。
- v1.4.15（2026-09-01，tag v1.4.15）：新增 TypeScript 客户端 `@agentica-ai/sdk` 与 Gateway Docker 镜像；`/export` 默认输出 session JSONL。

- v1.4.12（2026-08-10，tag v1.4.12）：新增跨终端 peer 消息（`list_agents` / `send_message`）与进程级 `delegate`（`/ps` `/stop` `wait` 托管）。
- 更早：OpenAI Responses API（v1.4.11）、cron 运行时与自管理（v1.4.7）、LSP 诊断与 `/goal`（v1.4.6）、后台记忆抽取（v1.4.4）、`SkillLifecycleHooks`（v1.4.3）。

## 修复
- v1.4.15：`apply_patch` 只做精确匹配；CLI 不再把工具输出中的 `[/path]` 当 Rich 标记。
- v1.4.12：修复 read-and-reread 循环与 Anthropic 路径上淘汰逻辑不生效的问题。
- v1.4.11：修复 Learned Experiences 污染与 `write_todos` 全量回显。
- v1.4.9：修复 `ask_user_question` CLI 卡死。
- v1.4.7：修复流式上传 OOM 与 `/api/upload` 路径穿越（CWE-22）。

## 重构
- v1.4.16：MCP 收敛为仅支持 2.x；压缩三层收敛为两层语义（截断/淘汰 + 空窗换窗）。
- v1.4.14：文件工具收窄为 `apply_patch` + `write_file`（`read_file` 支持 tail）；Worktree 默认进仓库内；权限档对齐 Codex（ask 不再隐藏写工具）。
- v1.4.13：Web UI 由旧形态重构为 Vite + React SPA；界面默认英文、设置可切中文。
- v1.4.3：Skill 生命周期重构 + VaG 解耦。

## 破坏性变更
- MCP 仅支持 2.x（v1.4.16）——依赖 mcp 1.x 的用户需升级。
- `edit_file` 被收窄移除、由 `apply_patch` + `write_file` 取代（v1.4.14）——脚本化调用方需迁移。
- Layer 2 compact 不再产出 LLM 摘要（v1.4.16）——依赖摘要轮行为的下游集成需改用 `search_session`。
